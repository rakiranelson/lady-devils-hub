## MVP Scope
### Users should be able to:
- Create events
- Create announcements
- Edit events (also cancel and delete)
- Edit announcements (also pin/unpin and remove)
- View upcoming and past events
- Filter events by category
- View announcements

### Bugs and Issues encountered
- For one of the users, when they created events and announcements, it duplicated them (not sure why yet)
- For another the users the edit event modal kept closing on them, and they had to start over to create an event
- People commented on how navigation back to the overview page wasn't the post intuitive at first

### Visual Suggestions
- Some people said the overall pages were maybe a little dark. Some suggestions for more contrasting colors
- Make some of the labels (e.g. announcements, events, wristband playbook) thicker
- Users did say that things were visually clear and straightforward

### Usefulness and Future Improvements
- The overall consensus is that this should be a platform for (active) players since most information would be applicable to them.
- Multiple people mentioned Google Calendar integration
- Someone mentioned GroupMe integration. (I'm unsure about what type of integration they have in mind)
- Someone said an upcoming registrations deadlines tab
- When some people were doing the demo, for creating an event, I noticed they navigation to the events page first. Maybe I could add a "add an event" shortcut on the events page that only appears to those on exec.
- Someone mentioned how the analytics section could be useful "when thinking about playing time/ who is invited to tournaments, or just general player retention info."
